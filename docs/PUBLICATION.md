# 公开仓库的内容边界

发布源来自已修改的下载版源码，而非开发者的个人工作目录。首次提交建立全新历史，不导入此前的本机 Git 历史。

已排除：`.git`、`.vs`、`bin`、`obj`、`.minecraft`、PCL 运行数据、日志、INI 设置、用户工程配置、调试符号、EXE、证书及私钥。
保留构建所需的上游资源 DLL/JAR/字体/图片/帮助文件，未包含个人编译出来的启动器二进制。

Microsoft Client ID、CurseForge Key 和上报地址均无内置值。ID 与 Key 只能通过本机环境变量显式配置。
本仓库不包括开发者的登录缓存，也不自动读取其它启动器的账号或凭据。

提交前可在仓库根目录运行 `python tools/check_public_source.py` 进行基本的凭据和文件检查。
该检查用于防止常见误提交，不能替代对新增内容的人工检查。
